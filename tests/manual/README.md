# WEM Inquiry 手工回归测试页

1. 仅在测试站点将 `page-wem-inquiry-test.php` 放入当前启用的 Classic Theme 根目录。
2. 创建页面并选择 **WEM Inquiry Privacy Test** 模板，使用虚构姓名、电话、邮箱和消息提交。
3. 管理员访问该测试页执行匿名 REST / Feed 自请求诊断；同时使用无痕浏览器确认单条评论读取返回 404。
4. 诊断无法判断的 HTTP 530 不视为通过；管理员误批准测试仅用虚构数据。
5. 该页面包含检查工具，但不保证覆盖所有分页、第三方代码或直连数据库的场景。
6. 完成测试后，从生产主题中移除诊断模板，不要暴露调试环境。

详见 `wem-inquiry/README.md` 的安全与验收章节。
